# End-to-End ML Pipeline

> **Main entry point: `run_benchmark.py` — the Continuous RUL Benchmark (CRB).**
> Protocol, metrics, baselines and the proposed CATT + TCT are specified in
> [`../BENCHMARK.md`](../BENCHMARK.md). Code: `benchmark.py` (protocol), `models/deep.py`
> (all deep models + shared trainer), `run_benchmark.py` (runner + leaderboards).
>
> The rest of this page describes the earlier within-family comparison scripts.

Compare models **within each dataset/family** using that family's native metrics (no cross-family accuracy ranking).

## Families

| Family | Datasets | Primary metric | Also report |
|--------|----------|----------------|-------------|
| **RUL** | CMAPSS FD001–FD004, PHM08, N-CMAPSS | continuous RMSE (↓) | MAE, R², PHM Score, last-window RMSE |
| **SCANIA** | Component X | Total_cost (↓) | macro-F1, per-class recall, accuracy, % vs. Always-4 |

## Evaluation protocol

- **Continuous sliding window**: train/val use every overlapping window (step 1).
- **Test scoring**
  - *continuous* (primary): every window over each test unit's history.
  - *last-window*: final window per test unit (classic CMAPSS benchmark, for comparison with papers).
    PHM08 held-out units are cut at 5 random cycles before failure first; N-CMAPSS has no last-window
    score because its test units run to failure (last window is always RUL 0).
- **Seeds**: every model runs over `--seeds` (default 42 43 44); results are mean ± std.
- **Trivial baselines** are always reported: `MeanRUL` (RUL), `Always-0` / `Always-4` (SCANIA).
  On SCANIA test, Always-4 already costs 49,671, so a model must beat that to have learned anything.
- **Selection** (e.g. condition clustering vs. plain) uses validation RMSE only, never test.
- Splits are by unit/vehicle; scalers are fit on training data only.

## Run (Google Colab, T4 GPU)

Open `colab_run.ipynb` in Colab (Runtime → Change runtime type → T4 GPU) and run all cells.

Locally:

```bash
python ml_pipeline/run_family_comparison.py          # all RUL sets + SCANIA, 3 seeds
python ml_pipeline/run_condition_rul.py              # FD002/FD004 condition clustering
python ml_pipeline/run_scania_cost_tune.py           # SCANIA cost-aware decoding
python ml_pipeline/run_n_cmapss_multi.py             # needs N-CMAPSS .h5 (NCMAPSS_DIR)
python ml_pipeline/run_ablation.py                   # LSTM one-factor ablations
```

Useful flags: `--seeds 42 43 44 45 46`, `--skip-scania`, `--scania-windows-per-vehicle 0` (every SCANIA window; needs a lot of RAM).

Results: `ml_pipeline/results/` (regenerated by the scripts above).

## Adding a model

Add it to `make_models()` in `run_family_comparison.py`. Any object with
`fit(X, y, X_val, y_val)` and `predict(X)` on `(N, T, F)` windows works, and it is
then evaluated with the same windows, seeds, metrics and baselines as everything else.
